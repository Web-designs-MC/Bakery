# Bakery Menu Planner

A small web app for a home bakery: recipes with photos, ingredient costs, suggested selling prices, a price list and an equipment checklist. Prices are in rand (ZAR).

## Use it

Open the GitHub Pages link for this repository. Everything saves automatically in your browser on that device.

- **Download backup** saves a `.json` file with all your recipes, ingredients, prices, equipment and photos. Keep it somewhere safe (e.g. Google Drive).
- **Open backup** loads that file on another phone or computer.

## Put it online (GitHub Pages)

1. Upload `index.html` (and this README) to the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.
