Connect Google Drive

One-time setup in Google Cloud Console. Paste the Client ID it gives you below.

  1. Go to console.cloud.google.com and create a project (e.g. “Bakery App”).
  2. APIs & Services → Library → enable Google Drive API.
  3. OAuth consent screen → External → fill in the app name and your email, add the scope .../auth/drive.file, and add your Gmail under Test users.
  4. Credentials → Create credentials → OAuth client ID → Web application. Under Authorised JavaScript origins add
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it here.
